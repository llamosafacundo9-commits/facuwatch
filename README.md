# FacuWatch

App web personal para un reloj Moyoung (F22c). Se usa desde el iPhone dentro de
**Bluefy** (navegador con Web Bluetooth) y habla directo con el reloj.

- Los datos de salud se guardan **solo en el teléfono** (IndexedDB). Este
  repositorio contiene únicamente el código de la app y los diseños de esferas.
- Solo envía al reloj comandos documentados por Gadgetbridge y aprobados uno a uno.
- Proyecto personal, sin fines comerciales.
